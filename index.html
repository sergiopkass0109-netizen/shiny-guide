n gives the n-th prime for any 1 ≤ n ≤ 2×1014 — commas, 1e9 and 10^k all work. pi(x) counts the primes up to x (to 9×1015). N? tests whether N is prime — deterministic to 3.3×1024, in polynomial time. Every result gets a shareable link.

Exact for every 1 ≤ n ≤ 2×1014 — the frontier of exact 64-bit-float integer arithmetic (answers stay below 253). This page is one self-contained file — saving it works. Verified against OEIS A006988, π(10k) reference values, and an independent sieve. Math: Cipolla (1902) & Gram series for the estimate, rigorous Rosser/Dusart brackets, Lucy_Hedgehog counting, architecture after primecount; every result reachable by two independent algorithms (Lucy_Hedgehog and Lagarias–Miller–Odlyzko) that are cross-checked in the test suite. Heads-up: n = 1012 takes ~15 s, 1013 ~2 min, beyond that is best run in a desktop browser or the Node CLI.
